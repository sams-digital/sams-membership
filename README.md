## 🔐 Membership Verification

After payment:

1. Student selects a membership plan.
2. Student completes the payment.
3. Payment details are saved securely.
4. Student sends the receipt through WhatsApp.
5. SAMS Admin verifies the payment.
6. A unique Member ID is generated.
7. A unique ID Card Number is generated.
8. Membership is activated.
